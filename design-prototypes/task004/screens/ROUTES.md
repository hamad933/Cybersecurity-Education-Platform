# Prototype screen routes

The eight linked local views are rendered inside `../index.html` by hash route:

- `#dashboard`
- `#sources`
- `#knowledge`
- `#curriculum`
- `#lab`
- `#enterprise`
- `#evidence`
- `#manual-ai`

This keeps one unified product shell while only one workspace is active. The proof uses representative synthetic data and does not implement persistence, processing, simulation, AI calls, or product services.
