This directory is a **NON_CANONICAL_EXECUTION_REFERENCE_MIRROR** for CEP executors and reviewers.

Canonical ownership remains in Google Drive under the governed CEP visual/reference library.
The repository copy exists so GitHub-native cloud executors such as Jules can consume the accepted
reference material without direct Google Drive access.

Publication source baseline:
- repository: `hamad933/Cybersecurity-Education-Platform`
- integration branch: `build/cep-v1-integration`
- expected integration SHA: `b5d53d2d44c570ebf112c50bec966da01835e5d9`

The 11 original PNG files were downloaded from the accepted Drive package and verified against
`manifests/SOURCE_PACKAGE_MANIFEST.sha256` before derivative creation.

Published images are full-dimension JPEG quality 97 / 4:4:4 execution derivatives.
For every reference, `REFERENCE_CATALOG.json` records both:
- accepted original PNG SHA-256;
- published derivative SHA-256.

The published derivative is for visual execution/review. It does not replace the canonical Drive binary.
