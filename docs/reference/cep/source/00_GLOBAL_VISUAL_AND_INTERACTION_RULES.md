# Global CEP Visual / Interaction Rules

The final contract fixes the following global destinations:

- اليوم
- المعرفة والتعلّم
- المحاكاة والمؤسسات
- التقدم والأدلة
- النظام والعمليات

Global workspace law:

- `TOP` = tools / modes / current workflow actions
- `LEFT` = structure / navigation only
- `CENTER` = actual primary work
- `RIGHT` = unique contextual information only
- `BOTTOM` = temporary deep workspace, closed by default

Core information-ownership law:

`ONE INFORMATION ITEM → ONE AUTHORITATIVE DISPLAY LOCATION`

Additional invariants:

- `CANONICAL OWNER ≠ WORKSPACE SURFACE ≠ CONTEXT OF CREATION`
- `Result ≠ Evidence`
- `Candidate Evidence ≠ Evidence`
- `Evidence ≠ Artifact`
- `Review ≠ Decision`
- `Decision ≠ Mastery`
- `Completion ≠ Mastery`
- `Progress ≠ Mastery`
- `AAR ≠ Evidence Review`
- `Research & Quality Review ≠ Evidence Review`

Arabic is the primary UI direction. Technical IDs, code, URLs, and English technical tokens remain controlled LTR.
