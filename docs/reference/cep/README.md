# CEP Execution Reference Mirror

Status: `NON_CANONICAL_EXECUTION_REFERENCE_MIRROR`

This directory makes the accepted CEP visual/reference package usable by GitHub-native cloud executors
and reviewers. Google Drive remains the canonical owner of shared visual/reference assets.

## Before using an image

Read, in order:

1. `AI_RENDERING_EXCLUSIONS.md`
2. `source/CEP_VIS_001_FINAL_VISUAL_AND_INTERACTION_CONTRACT_v1.0_APPROVED.md`
3. the applicable file in `notes/`
4. the image in `images/`

The images communicate composition, hierarchy, information ownership, interaction intent, density,
and visual grammar. Do not reproduce image-generation errors or illustrative fake data.

`REF_01` is the golden structural reference. `REF_02`–`REF_11` are `REFERENCE_ONLY`.
