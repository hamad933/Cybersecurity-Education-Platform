# Responsive Behavior

## Desktop (>= 1200px)

Global navigation remains visible. Complex review/authoring may use context/main/inspector panes with independently bounded scroll. Main content has a readable maximum width where prose dominates.

## Tablet (768–1199px)

Navigation becomes compact. Context may remain narrow; inspector becomes a labelled drawer. Tables preserve essential columns and expose details through an accessible row action. Graphs have list equivalents.

## Mobile (< 768px)

Navigation opens from a visible menu button and closes on selection/Escape. Content follows semantic source order. Panes become one column; context and inspector are explicit sheets. Sticky actions cannot cover focus or error text. Wide code/trace/table content scrolls inside its component, not the page. No critical action depends on hover or drag.

Test viewports are 1440x1000 desktop, 1024x768 tablet, and 390x844 mobile, plus 200% zoom/reflow. Required Task 004 mobile evidence covers Dashboard/navigation, Lesson Reader/Editor, and Guided Lab.
