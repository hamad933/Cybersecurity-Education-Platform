# Guided Lab Interaction

The Guided Lab header names `VS-001`, current baseline/scenario/rule revisions, `DESIGN PROOF` or implementation state, simulated professional role, device context, and a persistent **SIMULATED** label.

The context area presents objective, prerequisites, target capability, evidence requirements, and optional hint policy. The action panel uses structured authorization inputs—principal, user/group SIDs, privileges, target, descriptor/DACL, requested mask, generic mapping—rather than a host terminal. Submit is labelled `Evaluate simulated decision`.

The result view distinguishes applied, permission failure, syntax/parameter failure, unsupported state, and insufficient state. It shows the ordered rule/ACE trace, mask changes, outcome, limitations, logs/findings/evidence, remediation, and verification. Reset and replay name their effects. Hints and retries are recorded. Evidence capture previews origin, run/revisions, trace digest, and criteria before submission.

Mobile orders objective -> inputs -> result -> evidence, with a sticky status/action region that does not cover focus. Code/trace remains horizontally scrollable inside its own LTR region without page-level overflow.
