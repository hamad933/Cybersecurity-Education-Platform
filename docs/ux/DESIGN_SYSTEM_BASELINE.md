# Design System Baseline

## Visual language

The interface uses a dark navy application shell, light neutral work surfaces, cyan for navigation/selection, indigo for structured authoring, green for accepted/published, amber for warnings/provisional states, red for denied/failed/destructive states, and violet for Manual AI proposals. Color is always paired with text/icon/pattern.

Typography uses the local system font stack; no CDN or Internet font. Arabic line height is generous; technical monospace uses a local fallback. Spacing follows a 4/8-pixel rhythm. Corners and shadows are restrained for a dense professional tool.

## Components

Required primitives include skip link, global nav item, workspace header, breadcrumb, status badge, provenance chip, tab list, disclosure, field/help/error group, data table, card, timeline, graph/list dual view, code/trace block, toast/status region, drawer/dialog, confirmation, empty/error/loading state, and primary/secondary/destructive buttons.

Minimum pointer target is 44px where practical. Focus is a 3px high-contrast outline with offset. Error text is connected to fields. Tables have captions and headers. Motion respects reduced-motion preference.
