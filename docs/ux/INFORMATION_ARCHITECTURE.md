# Information Architecture

The product is one workspace system with eight principal destinations and contextual sub-workspaces, not one giant page.

1. **Today** — dashboard, daily queue, open reviews, evidence gaps, recent activity.
2. **Sources** — Source Library, custody detail, extraction, segments, authority, claims/conflicts.
3. **Knowledge** — Knowledge Studio, Lesson Reader/Editor, revisions, citations, impact.
4. **Curriculum** — Domain -> Cluster -> Capability -> KU, paths, prerequisites, coverage gaps.
5. **Labs** — Guided Labs, active Run, devices, decisions, deterministic trace, hints, evidence.
6. **Enterprise** — persistent catalogs, baseline revisions, Scenario Studio, packages, Runs.
7. **Evidence** — attempts, evidence, mastery, review queue, portfolio.
8. **Manual AI** — packages, export scope, imports, validation, proposed diffs, human decisions.

Administration functions—owner/session, audit, processing, packages, search, backup/restore, health—remain accessible through a utility menu and do not become an unrelated workspace.

Every record exposes stable ID, owner module, revision/state, provenance or limitation, and recent audit. Global search returns authorized typed results and never flattens source, canonical knowledge, lessons, and learner state into one authority level.
